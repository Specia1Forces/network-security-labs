# Лабораторные работы по защищённым сетям

Четыре учебные работы по курсу «Основы построения защищённых компьютерных сетей». Стенды собраны в Cisco Packet Tracer.

**[Отчёт по лабораторным работам (PDF)](network security labs.pdf)**

## Что сделал

| Лабораторная | Практическая работа | Страницы отчёта |
| --- | --- | --- |
| Проектирование сети | Спроектировал топологию для двух отделов, составил план IP-адресации и таблицу портов. | 2–5 |
| Настройка маршрутизатора Cisco IOS | Настроил сетевые интерфейсы, статический маршрут по умолчанию и локальную аутентификацию на консоли. | 5–13 |
| Сегментация сети | Настроил две VLAN, порты access и trunk 802.1Q. Проверил доступность узлов из разных сегментов с помощью `ping`. | 13–25 |
| Настройка межсетевого экрана Cisco ASA | Настроил внутренний и внешний интерфейсы, DHCP и SSH-доступ из локальной сети. Проверил открытие страницы тестового HTTP-сервера. | 25–42 |

В конце отчёта разобрал зондовую маршрутизацию на примере DSR и AODV (стр. 43–44).
